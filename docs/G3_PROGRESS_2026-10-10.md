# LOCAL3D G3 quality and benchmarking milestone (2026-10-10)

**Status: CPU geometry diagnostics and reproducible nine-image source dataset BUILT and TESTED; full AI multi-fixture comparison has NOT been run.** This release is explicitly a G3 PREVIEW, not a full quality qualification or a new provider approval. G1 still defaults to CPU DEMO, G2 only manual per-image approval and Windows GPU conflict checks.

## Completed without any new model inference

### 1. Benchmark source catalog
- scripts/g3_make_fixtures.py creates eight project-original procedural source images with pixel-level masks and authoritative source 3D models; plus a ninth licensed TripoSR upstream photo/mask, for which no ground-truth CAD exists.
- Stored in benchmarks/g3/fixtures with SHA256 manifest locking source image, mask and ground-truth mesh (for eight). Generated twice, byte-for-byte repeat verified; 26 files ~310KB. No third-party generated media is incorporated into the eight originals.
- Shapes cover transparent/opaque matched object, hollow vessel, torus with through-hole, separate parts, thin chair geometry, toothed outline and arch/overhang.
- Exact-source-camera positive-control silhouette projections all exceeded 0.935 IoU, MIN **0.935812**. These are tests of the scorer consistency, **NOT** TripoSR prediction accuracy.

### 2. Independent CPU-only topology/geometry inspection
- engines/quality/geometry_qa.py parses existing GLB with Trimesh after strict GLB header, version, byte-count and mesh-size checks.
- Reports unmodified indexed mesh topology: boundary/nonmanifold edges, duplicate index triangles, relative zero-area faces, connected components, watertightness, signed volume, positive-volume status, world-unit-free bounds and face/vertex counts.
- Explicit NOT_TESTED for self-intersections, thickness, supportability, intercomponent interference, strength and real-world scale. **printQualified=false always.**
- Analyzing G2's real image-to-3D chair found 19,972 triangles, 1 connected component, 0 open boundary edges and consistent winding. The **signed volume is NEGATIVE −0.0613843** arbitrary cubic units, so positiveVolume=false. This is a genuine geometric defect signal not surfaced by earlier watertight checks; it is not a calibrated real-world volume.

### 3. A constrained, provenance-preserving orientation derivative
- engines/quality/orientation_derivative.py runs **only upon explicit CLI invocation** on an existing GLB, refuses multi-part/open/inconsistent/unmodified positive-volume meshes and refuses overwrites.
- For the known real chair, reversed triangle winding on a **separate** derivative and independently validated signed volume +0.0613843, same 19,972 triangles, one component and same AABB extents.
- Original GLB SHA ed50855c7e2f6a3cd0ab884a41d44a13c2ea86a3d14f04c05b9e889160429416 unchanged. Derived GLB SHA 48ee912229ad73fcbda1a6b455dbcc39d396bdf2c752ccabc90a29097b09b6ec.
- This corrects inward winding, not arbitrary topology/holes/thickness; **does not establish printability**. No automatic repair or upload of derivative to the app was introduced.

### 4. Geometry review integrated into existing LOCAL3D API and Chrome UI
- On an already **completed manual TripoSR** job, click **סריקת רשת (CPU)** to request a one-time CPU review. New endpoint POST /v1/jobs/:uuid/review (no uploaded path, no GPU instruction).
- Server verifies the completed real GLB against job manifest SHA and bytes **before** launching isolated CPU Python scanner. One review lease per job; second request 409. A signed, DRAFT-only geometry-qa.json asset appears after SHA and qualification guards pass. No report is exposed on failure.
- Browser displays watertight state, positive volume status, component count and explicit missing dimensional/strength qualification. A downloadable detailed JSON report is available. G1 DEMO and incomplete jobs cannot run G3 review.
- Actual LOCAL3D Chrome/browser proof used the **existing** real G2 GLB and the actual isolated Python reviewer, without any new neural inference. 0 worker GPU calls, 0 external browser URL requests, 0 JS errors, signed-volume warning displayed. Temporary test service closed.

### 5. Provisional silhouette score for existing chair
- engines/quality/silhouette.py reports relative 2D mask overlap from projected mesh triangles, normalizing both masks the same way.
- Existing real chair mask and generated model: 24 searched yaw/elevation views, best IoU **0.82448**, labelled **EXPLORATORY_UPPER_BOUND** (selection after seeing source mask, no calibrated camera, no ground-truth chair CAD).
- Do not extrapolate this to photorealistic reconstruction performance or manufacturing quality.
